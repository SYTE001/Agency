# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Send a private report to the repository maintainer with the affected version, reproduction steps, impact, and any suggested mitigation.

Please avoid including credentials, production data, or personal information in the report. We will acknowledge reports as soon as practical and coordinate disclosure after a fix is available.

## Supported versions

The default branch is the supported development line. Security fixes should be backported only when the maintainer confirms that the affected release is still deployed.
