LOCKED TIGHT, BY DEFAULT

Built on verifiable
engineering foundations.

Strict tenant isolation, cryptographic session management, and server-side authorization — protecting client contracts and financial records.

Tenant Isolation

Every record — creator, brand, campaign, commission — is scoped by agencyId. Cross-tenant access is blocked at the database level.

Server-Side RBAC

Eight distinct roles, Owner to Viewer. Permissions validated on the server for every read, mutation, and server action.

Cryptographic Sessions

Pinned HMAC-SHA256 JWT in httpOnly cookies. Issuer and audience verified on every request; roles re-read from the database.

Password Security

Salted scrypt hashing protects all credentials. Plain text is never stored or logged — anywhere.

Relational Schema

PostgreSQL with strict foreign keys, Decimal-precision money values, and indexed query paths throughout.

Timezone Engine

All operational dates, studio shifts, and GMV reports render consistently in your agency's designated timezone.
